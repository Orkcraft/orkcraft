A control room for coding agents · alpha

Build the factory that builds your side project.

Your coding agents as a town you grow after work. Work comes in, the orks refine it on the line, you pass it at the gate, and finished goods are catapulted over the wall.

Install in one line (macOS, Linux)

curl -fsSL https://orkcraft.dev/install.sh | sh

It puts uv, a Python and Orkline in place, logs each step, and opens the town. Read the script first. With Homebrew: brew tap orkcraft/orkcraft https://github.com/Orkcraft/orkcraft then brew install orkcraft/orkcraft/orkcraft. Try orkline --demo for a sandbox town: nothing real is touched and no model is called.

A factory, not a dashboard

Every task is a cart. It has one life, and you learn its shape once.

  1. Work comes inFrom External listeners (mail, GitHub, a webhook), the Task board, or the town's clock at its hour.
  2. The lineCarts roll down roads between buildings. In the Agent pool the orks (your Claude Code, Codex or Antigravity sessions) do the work; scripts do what needs no model.
  3. The Review gateNothing leaves without your nod. A result waits for you with its diff; you pass it or send it back.
  4. The PublisherThe passed cart is launched: a pull request opened, a reply sent. Drawn in Camp as a catapult at the wall.

The score: less wood per accepted result

🪵 Wood is tokens. The game is not to spend less in total, which doing nothing wins, but to spend less wood and less of your plan's limit for each result you accept. The cheapest thing that works wins: a script before an agent, a smaller model where it is enough.

How it differs

Other tools show your agents. Orkline runs the work.

Tasks go down roads between buildings, through a review gate, and the game is spending less per accepted result. Several vendors in one town; you see who is working, who waits for you, and what each result cost.

What it is not

  • No cloud. The town runs on your computer; your code stays there.
  • No API keys. It talks to models only through the command-line tools you already have: claude, codex, agy.
  • Your own subscriptions. Your sign-in, your plan's limits, with budgets you set and Stop all one click away.
  • Open source, Apache 2.0. Checked on macOS.
