# Landing videos

Filmed with `tools/landing_flow.py` (branch `claude/landing-flow`) from the demo's Front Desk orkspace, 1440×900 at 2×.

| File | Look | What happens |
|---|---|---|
| `landing-flow-camp.mp4` | Camp | A mail and a Slack message arrive at the Inbox and go through Triage. The mail goes down "task for human" to the person's to-dos. The Slack message goes down "task for agent" to the kanban, is done by Agents at work and lands in Done, and its result reaches Results with a link. |
| `landing-flow-office.mp4` | Office | The same flow in the Office look. |
