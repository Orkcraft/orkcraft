# Marketing materials for the launch of Orkline

Drafts for the owner. The launch has no date (decisions-2026-10.md §15): nothing goes out before the owner says the product is ready. Once planned from 19 October ([docs/design/launch-prep.md](../design/launch-prep.md)). Written in
English for the posts; the owner edits the voice before anything goes out. Nothing here is published by itself.

**Rules for every post** (CLAUDE.md, [similar-products.md](../design/similar-products.md) §4, Q18):

- write **ork**, **orkestration**; never name the big strategy game or compare the look to it; never say "your agents as
  pixel characters" (the category's line); never speak against another project;
- generated art is shown as **a concept**, said so (color-pass §10b), until the artist's work is in;
- "checked on macOS; Linux and Windows should work, not yet checked"; no phone promise beyond what works;
- one post per place, written for that place, and every reply answered within a day.
