# The community's home on Discord

Decided in [launch-prep.md](../design/launch-prep.md) §3: **Discord for talk** (with GitHub Discussions for ideas and
questions tied to the code). Opened with the first devlog post, **after the name is final** (it is: Orkline).

## Channels (few on purpose: an empty room reads as a dead project)

| channel | for |
|---|---|
| #welcome | one message: what Orkline is, the rules, links (GitHub, landing, the testers' guide) |
| #announcements | releases and devlog posts only (fed automatically from GitHub releases) |
| #general | everything else |
| #show-your-camp | screenshots of people's towns and what their orks built |
| #help | install and usage questions |
| #ideas | ideas; good ones get a GitHub Discussion or issue |
| #testers | the first testers (private until the launch) |

Add a channel only when a topic fills #general for a week.

## Rules (in #welcome)
1. Be kind; no harassment, no slurs.
2. No promotion of other products unless asked.
3. Bugs: steps, OS, a screenshot; security issues privately to the owner, never in public.
4. What you share in #show-your-camp may be reposted with credit; say if you'd rather not.

## The first week
- The owner answers every message within a day.
- One small question a day in #general ("what are your orks building this week?").
- Invite testers personally into #testers.
- **Measure** ([launch-prep.md](../design/launch-prep.md) §4): people in the Discord, active in the last week.
