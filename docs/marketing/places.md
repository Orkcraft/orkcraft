# Where the first audience is, and how to show up there

The first audience: **developers who build their own things after work with coding agents and enjoy optimising
systems** ([audience.md](../design/audience.md)). Rules change; **read each place's current rules the day before
posting**. What's below is how these places usually work, not a guarantee.

| place | who | how it usually treats self-promotion | what to post | when |
|---|---|---|---|---|
| **Claude Code communities** (the subreddit, its Discord, GitHub Discussions of tools around it) | heavy Claude Code users | show-and-tell of tools is welcome when it is a real tool, open source, and the author answers questions; flair or a weekly thread may be required | the devlog post, the GIF when it exists, "what I learned running N agents on my side project" | from 19 Oct, devlog #1 |
| **r/SideProject, r/indiehackers, Indie Hackers** | side-project builders | "show your project" posts allowed; the story counts more than the features | the commute-home story and the factory, with the concept frame | week of 19 Oct |
| **Developers who talk about factory games** (communities of automation games, their off-topic channels) | people who enjoy optimising | off-topic channels only, if at all; never in the game's main channels | the score ("less wood per accepted result"), the rails and the line | after the GIF |
| **Hacker News (Show HN)** | developers broadly | one Show HN per project when it is usable by others; the author answers in the thread for hours | "Show HN: Orkline — run Claude Code and Codex on your side project as a factory you can watch" | **at the public launch only**, with the hand-drawn art and the GIF |
| **X, Bluesky, Mastodon, LinkedIn** | the broadcast | the owner's own accounts | each devlog post and release, mirrored (the broadcast goes through the town's Review gate, [launch-prep.md](../design/launch-prep.md) §3) | from 19 Oct |
| **Pixel Agents' Discord and similar projects' communities** | the category's users | **never promote there**: read, learn what people ask for ([similar-products.md](../design/similar-products.md) §2) | — | — |

**Every place:** one post written for it, not the same text pasted; reply to every comment within a day; no
upvote asks; no second account.
